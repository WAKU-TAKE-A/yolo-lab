# YOLO-Lab 開発計画書
作成日: 2026-06-05

## 1. 背景

YOLO / ONNX / GPU 環境の検証を行う際、これまでは都度その場限りの Python スクリプトを作成したり、毎回異なる手順で評価したりしていた。

その結果、以下の問題が発生している。

- 毎回 YOLO / ONNX / CUDA / GPU まわりを調べ直している
- 生成AIに依頼しても、前提情報や環境情報が不足し、判断がぶれる
- 評価結果・推論画像・環境情報が一貫した形式で残らない
- モデルやONNXの検証が、その場限りの作業になり再利用できない
- GUIアプリを作っても、入力画面中心の作りでは形骸化しやすい

本プロジェクトでは、YOLO便利ツールではなく、以下を目的とする。

```text
生成AIがYOLO/ONNX検証を一貫した手順で実行するための共通実行基盤
````

主役はGUIや便利コマンド集ではなく、共通化された評価・検証ランナーである。

---

## 2. 基本方針

### 2.1 目的

以下を実現する。

```text
その場限りのPythonスクリプトで確認しない。
毎回違う方法で評価しない。
YOLO/ONNX/GPU環境の確認を共通化する。
生成AIが同じ作法で実行・記録・比較できるようにする。
必要なら画像結果も人間が確認できるようにする。
```

### 2.2 生成AIファースト

このツールは、人間が細かくGUI操作することを主目的にしない。

主な利用者は以下の2者である。

```text
生成AI:
  コマンドを実行し、JSON/Markdown/画像結果を読み、次の判断を行う

人間:
  必要に応じて summary.md や annotated 画像を見る
```

したがって、すべての実行結果は以下の形式で残す。

```text
生成AI向け:
  JSON

人間向け:
  Markdown
  annotated画像
  必要に応じてHTML
```

```text
初期段階の単体スクリプト:
  pc-check.py
```

---

## 4. 3本柱

必要な機能は大きく3系統に分ける。

```text
1. pc
   PC環境・GPU・CUDA・PyTorch・ONNXRuntime確認

2. yolo
   Ultralytics YOLOモデルの推論・評価・学習・エクスポート

3. onnx
   ONNXモデルの構造確認・推論・YOLO結果との比較
```

この3本柱に絞り、不要な便利機能を増やさない。

## 6. 初期フェーズでは pc-check.py から開始する

最初から ylab.py 全体を作らず、まずは `pc-check.py` を作る。

理由:

```text
YOLO/ONNX検証の前提はPC環境である。
GPU、CUDA、PyTorch、ONNXRuntimeの状態が分からないと、以降の検証結果を解釈できない。
pc-check.py は単体でも価値があり、後で ylab.py pc check に統合できる。
```

初期構成は以下。

```text
yolo-lab/
  .venv/
  pc-check.py
  requirements.txt
  runs/
    pc_check/
```

# 7. pc-check.py 仕様

## 7.1 目的

`pc-check.py` の目的は以下。

```text
YOLO / ONNX 検証を始める前に、
このPC環境で何が使えるかを機械判定できるようにする。
```

特に以下を確認する。

```text
Python / venv
OS / CPU / RAM
NVIDIA GPU
NVIDIA Driver / CUDA
PyTorch
ONNX / ONNX Runtime
Ultralytics / YOLO
OpenCV / 画像処理系
```

---

## 7.2 実行方法

基本実行:

```bash
python pc-check.py
```

モデルロードテストあり:

出力先指定:

```bash
python pc-check.py --out runs/pc_check/test01
```

dry-run:

## 7.5 判定レベル

`status` は3段階。

```text
OK
WARN
ERROR
```

意味:

```text
OK:
  YOLO/ONNX検証に必要な主要環境が揃っている

WARN:
  動く可能性はあるが、注意点がある
  例:
    - venv外
    - ONNXRuntime GPUなし
    - nvccなし
    - VRAM少なめ
    - NVIDIA GPUなしだがCPU推論は可能

ERROR:
  主要機能が使えない
  例:
    - torch import不可
    - ultralytics import不可
    - onnxruntime import不可
    - Python versionが古すぎる
```



---

## 8.4 NVIDIA Driver / CUDA

ここは混乱しやすいため、複数の情報を分けて記録する。

確認するもの:

```text
NVIDIA Driver が対応している CUDA version
PyTorch がビルドされた CUDA version
実際に torch.cuda が使えるか
ONNXRuntime GPU provider が使えるか
CUDA Toolkit / nvcc が入っているか
```

チェック項目:

```text
NVIDIA driver version
nvidia-smi CUDA version
nvcc が使えるか
nvcc version
CUDA_PATH
```

出力例:

```json
{
  "cuda_driver": {
    "driver_version": "555.85",
    "nvidia_smi_cuda_version": "12.5",
    "nvcc_available": false,
    "nvcc_version": null,
    "cuda_path": null
  }
}
```

判定:

```text
OK:
  nvidia-smi が使える
  torch.cuda.is_available() が true

INFO:
  nvcc がない
```

重要な注意:

```text
nvidia-smi に出る CUDA Version は、
ドライバが対応している最大CUDA系統であり、
ローカルに CUDA Toolkit が入っていることを意味しない。

YOLO / PyTorch 実行だけなら nvcc は必須ではない。
PyTorch の CUDA 版 wheel を使う場合、CUDA Toolkit 未インストールでも動くことがある。
```

---

```text
GPU tensor計算が実際に通るか
```

```python

y = x + 1
```

出力例:

```json

    "version": "2.5.1+cu121",
    "compiled_cuda": "12.1",
    "cuda_available": true,
    "device_count": 1,

      {
        "index": 0,
        "name": "NVIDIA GeForce RTX 4060"
      }
    ],

```

判定:

```text

  cuda_tensor_test true

  torchは入っているがCPU版
  NVIDIA GPUはあるがtorch.cuda不可

```

## 12.2 onnx raw-predict


目的:

```text

```

## 12.3 onnx predict


## 12.4 onnx compare

PyTorch YOLO推論とONNX推論の比較。

```bash
python ylab.py onnx compare ^
  --pt best.pt ^
  --onnx model.onnx ^
  --source input/images ^
  --out runs/compare/pt_vs_onnx_01
```

## 15.5 dry-runは全コマンド共通

例:



dry-runでは、実際の推論・学習・エクスポート・ファイル変更を行わない。

# 17. 最初の実装タスク: pc-check.py

Codexで最初に実装する対象は `pc-check.py`。

## 17.1 必須要件

```text
- Python 3.10以上を想定
- venv内実行を推奨
- Windows対応
- UTF-8でファイル出力
- runs/pc_check/<timestamp>/ に結果保存
- env.json / env.md / command.txt を出力
- status は OK / WARN / ERROR
- import失敗は握りつぶさず、JSONに記録する
- 標準出力は短くする
```

## 17.2 チェック対象

```text
Python / venv
OS / CPU / RAM
nvidia-smi
NVIDIA GPU
NVIDIA driver / CUDA
nvcc
torch
onnx
onnxruntime
ultralytics
OpenCV
主要補助パッケージ
```

## 17.3 CLI引数

```text
--out
  出力先を指定する

--model-test
  Ultralytics YOLOモデルのロードテストを行う

--dry-run
  実行予定だけ表示し、ファイル保存しない

--json
  標準出力にもJSON概要を出す
```

## 17.4 エラー設計

```text
torch import不可:
  ERROR

ultralytics import不可:
  ERROR

onnxruntime import不可:
  ERROR

venv外:
  WARN

nvidia-smiなし:
  WARN または INFO
  CPU推論のみなら致命的ではない

nvccなし:
  INFO
  PyTorch wheel利用では必須ではない

CUDAExecutionProviderなし:
  WARN
  ONNX GPU推論には影響あり

OpenCV import不可:
  ERROR
  annotated画像出力に必要
```
